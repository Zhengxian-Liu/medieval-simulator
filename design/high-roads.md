# 往高處的路：主教、騎士、大商人、工匠師傅、官員

狀態：設計，2026-10-19。使用者原話：「希望主角能走的路放寬一點，可能性更高一點。雖然不是很符合史實，但是可玩性更高。例如主角一家後代有可能成為主教、騎士、大商人、工匠、政府官員等等的。」
這改了 GDD「階層流動」那一行（2026-10-16 寫的「個人一輩子很難換階層」）：往上的路要放寬，機會比史實高。開局有一個「路的寬窄」設定：
- 寬（預設）：好玩為主；
- 史實：照真實的機會。
跟[重點方向](focus-paths.md)一起做，方向就是這些路的入口。

## 現在的路走到哪就停了
`data/events/paths.json` 已經有孩子出去的路。可是每條走到第一、二階就停住：
- 文法學校 → 受神職，當村裡的神父；
- 替領主管帳；
- 鎮上學徒 → 入行會當師傅；
- 弓手 → 回鄉，或當領主的護衛。

沒有更高的一階，也沒有讓家裡跟著得好處的機制。

## 史實上真的有人這樣爬（放寬只是讓它常見一點）
- **威廉·威克姆**：自耕農的兒子，後來當上溫徹斯特主教和英格蘭大法官。
- **德·拉·波爾家**：赫爾港的商人，兩代就成了伯爵。
- **惠廷頓**：騎士家沒地可分的老三，去倫敦當布商，做過四任倫敦市長。
- **喬叟**：酒商的兒子，做了王室的官。
- **羅伯特·諾利斯**、**約翰·霍克伍德**：弓手出身，在法國打仗封了騎士。
- **亨利·耶維爾**：石匠，當上國王的總石匠。
- **強制受封**：年收入 40 鎊的地主會被強制受封騎士。所以種地的人家攢夠了地，也是一條路。

## 五條路，每條五、六階

| 路 | 入口（方向） | 階梯 | 走上去的條件 | 給家裡的好處 |
|---|---|---|---|---|
| 教會 | 信仰、學問 | 認字 → 文法學校 → 受小品 → 神父 → 牛津 → 主教府書記／座堂教士 → 主教 | 學問、有人舉薦、學費；農奴要領主放行 | 姪子上學、謀神職都有門路；領主和莊園法庭會給面子；能捐祈禱堂 |
| 騎士 | 弓箭 | 被徵去法國 → 弓手隊長（立功、分贖金）→ 給騎士當侍從 → 受封騎士 → 回鄉買下村裡的小莊園 | 弓箭、運氣、戰功；也可以靠 40 鎊的地被強制受封 | 家族成了鄉紳，走到頂就接上 GDD 已經定好的「騎士路線」，可以在同一個村子接著玩 |
| 大商人 | 手藝與買賣 | 小買賣 → 去鎮上幫商人跑腿 → 成為自由市民 → 羊毛商 → 市議員、市長 → 借錢給國王 | 口才、本錢、敢冒險；生意會賠 | 借錢給家裡不收利息；能把地買回村裡；女兒的嫁妝 |
| 工匠師傅 | 手藝與買賣 | 學徒 → 幫工 → 自己開作坊 → 行會的頭 → 接大工程（教堂、城堡）→ 國王的總匠 | 手藝、拜對師傅、作坊的本錢 | 收自家孩子當學徒；行會接濟；名聲 |
| 官員 | 學問、人情 | 莊園書記 → 管家 → 領主的總管 → 律師或王室書記 → 治安法官、郡長、議員 | 學問、口才、有人提拔 | 莊園法庭上有自己人；查得到地契和卷宗；選舉、爭地都有人撐腰 |

本村的路也接得更高：農奴 → 自由佃農 → 自耕農 → 小地主。小地主再往上一步，地多到年收 40 鎊，就會被強制受封，成為鄉紳。

## 怎麼玩
- **每一階是一張卡**：寫明機會多大，像 80 億分之一那樣標出成功的把握。
  - 家主要決定給不給錢、要不要寫信找人、要不要讓他冒險。
  - 失敗不是死路，會轉到另一條路，例如：
    - 牛津念不下去，回村當教區書記；
    - 在法國受了傷，回鄉當老兵；
    - 生意賠光，回來種地，還欠著債。
- **在外面的家人**一直是家裡的人。家裡欄有一塊「在外面的家人」，每人一行，寫：
  - 他在第幾階、下一步要什麼；
  - 能替家裡做什麼。
- **家人的身分就是槓桿**，放進現有的「開口」裡：
  - 請當主教府書記的叔叔替弟弟說句話；
  - 請當騎士的哥哥在莊園法庭上站在你這邊；
  - 向當商人的姑姑借錢。
- **爬得高，家族地位跟著升**：家族階梯多一格「家裡出了大人物」，墓誌銘也會寫進去。
- **交家時可以換線**：
  - 騎士和大商人走到頂、回鄉買了地的那一支，交家時可以選他接著玩，變成騎士或鄉紳家族，在同一個村子玩。
  - 主教不能娶妻，沒有後代，只能當家族的靠山。
  - 官員和鎮上的師傅先當靠山；要在鎮上接著玩，要等市鎮做好。
- **村民也會爬**：別家的孩子也會走這些路。對手家出了一個神父或管家，你就多了一個難纏的人。

## 機會放寬多少（「寬」設定）
- 史實上一個村子幾代才出一個神父，騎士更少。
- 「寬」的目標：一局四、五代裡，玩家家族認真去走，至少有一條路能爬到第四階以上；有一代能爬到頂，但要付出代價（錢、人、風險）。
- 數字寫在 `data/ladders.json`，每條路一個 `odds` 倍率，「史實」設定用 1。

## 要動的檔案
- 新 `data/ladders.json`：路、階、條件、機會、失敗轉去哪、給家裡的好處。
- `data/events/paths.json`：現有的路接上階梯，再補上每一階的卡，約 30 張。
- `src/life.cpp` 和 `src/ask.cpp`：在外面的家人當槓桿。
- `src/ambitions.cpp`：家族階梯加一格；可以換線交家。
- 介面：家裡欄的「在外面的家人」；在 `tools/ui/textplay.py` 裡也要看得到。
- GDD：「階層流動」那一行改成這裡的說法。
