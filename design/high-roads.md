# 人生的路：一張網，不是五條梯子

狀態：設計，2026-10-19 重寫。
使用者先說：「希望主角能走的路放寬一點……後代有可能成為主教、騎士、大商人、工匠、政府官員等等。」
上一版照那幾個例子抄成五條梯子。使用者批評：「不要只看我給出幾個選項就定幾條路，要有自己的思考。」
這一版從「14 世紀英格蘭的人實際上靠什麼往上爬、為什麼往下掉」想起。

## 想清楚的四件事

### 1. 往上爬靠的是幾種「力」，不是幾種職業
看真正爬上去的家族，靠的都是下面幾種力，往往一次用上兩、三種：

| 力 | 當時怎麼運作 | 誰靠它爬上去 |
|---|---|---|
| **靠山** | 幾乎每個爬上去的人背後都有一個主子。先進領主、修道院或主教家裡當差，再一路做到管家、總管 | 大部分的管家、律師、王室書記 |
| **法律** | 普通法是這個世紀新開的門。從莊園法庭的書記做起，到代訴人、律師學院、高級律師，最後當上法官 | 帕斯頓家：祖父是農民，兒子當上法官，孫子成了鄉紳，曾孫受封騎士，前後七十年 |
| **教會** | 唯一看本事的地方。可是不能娶妻，所以拉拔的是姪子，不是兒子 | 威克姆：自耕農的兒子，當上主教和大法官 |
| **戰爭** | 一場賭：抓到一個值錢的俘虜，一夜就能買地；也可能死在法國。1340–60 年代好賭，1370 年代以後輸多贏少 | 霍克伍德：硝皮匠的兒子，當弓手，後來在義大利帶傭兵團 |
| **市鎮和買賣** | 羊毛是全國的錢。逃進市鎮住滿一年零一天，就成了自由人。本錢會賠光 | 德·拉·波爾家：兩代從赫爾港的商人做到伯爵 |
| **婚姻** | 最快的一步。娶到有地的女繼承人或富寡婦，一場婚禮就換了階層 | 鄉紳家族幾乎都這樣擴張 |
| **時運** | 歷史本身會打開窗口。1349 年黑死病死了一半人，空地沒人種，工錢翻倍，農奴制鬆動；1360 年代以後領主反撲，窗口慢慢關上 | 一整批雇工家庭變成自耕農 |
| **膽子** | 偷獵、走私羊毛、加入亡命團、1381 年跟著起事。當時常有犯人用從軍換赦免，所以犯罪也能接上戰爭 | 福爾維爾幫就是鄉紳子弟組的亡命團 |

所以設計不做「職業梯子」，做「力」。每一步要哪一種力，每一種力從哪裡來，玩家能自己組合。

### 2. 一代爬上去的東西，要換成傳得下去的形式
- **人死就沒了**：官職、主子的恩寵、名聲。
- **傳得下去**：地、自由身分、騎士身分（要有地撐著）、聯姻結下的親戚。
- **最典型的戲**：父親當上總管，趁還在位時替兒子買地、娶一個有地的媳婦。沒趕上，兒子就從頭來過。
- **每一代的張力**就是「把這一代的運氣變成下一代的起點」。這也接上第 6 輪 D「每一代一條線」。

### 3. 女人佔家裡的一半，她們有自己的路
上一版完全沒寫女人。當時女人的路：
- **婚姻**：嫁得好，整個家族跟著升。
- **寡婦**：是女人法律上最自由的身分，拿得到三分之一的地，可以自己做生意、決定再不再嫁。富寡婦本身就是全村爭的對象。
- **釀酒婦**：村裡的釀酒婦，進了鎮就是釀酒商。瑪潔麗·肯普開過釀酒坊和磨坊。
- **修女**：一路做到女院長，管一整座莊園。
- **隱修女**：例如諾里奇的朱利安，有人遠道來求她指點。
- **產婆、醫婆**。
- **大戶人家**：當奶媽或侍女，進而做到夫人的貼身女伴。夫人會替她說親，嫁給侍從。
- **極端的例子**：愛麗絲·佩勒斯出身不明，當了國王的情婦，富可敵國，後來被國會清算。

### 4. 往下掉和走岔路，跟往上爬一樣重要
- **往下掉**：欠債、賣地、變成雇工、當乞丐，一輩子之內就會發生（GDD 原本的「往下掉很快」照舊）。
- **岔路不一定是壞事**：
  - 逃奴可能在鎮上翻身；
  - 偷獵的可能被赦免去從軍；
  - 被趕出牛津的學生，回村當教區書記，是村裡唯一識字的人。
- **失敗會轉進另一個身分**，不是死路。這是 80 億分之一最好玩的地方。

## 做法：身分網

### 身分（約 30 個，資料檔 `data/stations.json`）
- **村裡**：農奴、自由佃農、雇工、自耕農、小地主、莊頭、管家、磨坊主、酒館、教區書記、村神父、產婆。
- **大戶人家**：僕役、馬夫、侍從、侍女、貼身女伴、管家、總管、收租官。
- **法律**：法庭書記、代訴人、律師學院學生、高級律師、法官。
- **教會**：托缽修士、修士、修女、女院長、神父、座堂教士、主教、隱修者。
- **戰爭**：弓手、隊長、傭兵、加萊守軍、騎士。
- **市鎮**：學徒、幫工、師傅、行會頭、市議員、市長、小販、羊毛商、借錢給國王的大商人。
- **邊緣**：逃奴、盜獵者、亡命之徒、走私販、雲遊藝人、起事的人。

### 每個身分寫清楚五件事
1. **怎麼進來**：要哪一種力；從哪幾個身分可以走過來。
2. **給你什麼**：收入、在「開口」裡多出的槓桿、保護（例如神職人員犯罪只受教會審）。
3. **要付出什麼**：錢、離家、不能娶妻、風險。
4. **會遇到誰**：新的對手、新的主子。
5. **傳不傳得下去**：人死就沒了，還是能留給孩子。

### 身分之間的路
- **每一步是一張卡**：寫明要哪一種力、成功的把握多大，失敗轉到哪。
- **力從玩家的選擇來**：
  - 本事來自[重點方向](focus-paths.md)，它是本事的來源，不是路本身；
  - 靠山來自交情和服侍；
  - 錢來自家業；
  - 婚姻來自說親；
  - 時運來自歷史事件；
  - 膽子來自性格和選擇。
- **不寫死劇本**：同一個人可以「偷獵 → 逃 → 從軍換赦免 → 弓手 → 抓到俘虜 → 買地」，也可以「進伯爵家當馬夫 → 跟著主子打仗 → 侍從 → 主子做主娶寡婦 → 小地主」。路是組合出來的。

### 在外面的家人
- **身分就是槓桿**：家裡欄有「在外面的家人」，每人一行，寫他的身分和能替家裡做什麼。例如：
  - 當教士的叔叔能替姪子寫推薦信；
  - 當代訴人的兒子能在莊園法庭替你打官司；
  - 當侍女的女兒能替你在伯爵夫人面前說話。
- **交家時可以換線**：在村裡或附近有地的那一支（小地主、鄉紳、騎士），交家時可以選他接著玩。在鎮上或宮廷的，等市鎮做好再說。

### 村民也走這張網
- 別家的孩子也會走這些路，用的是同一套規則。
- 你的對手家出了一個代訴人，下次爭地就難打了。

### 寬窄
- 開局選「寬（預設）」或「史實」。
- 寬的目標：一局四、五代，認真經營的家族至少有一代爬進大戶人家、法律、教會或戰爭的中層，而且有機會出一個大人物。
- 寬的每一步都要有代價，不是白送。

## 給 Fable 試玩的問題（驗收）
1. 這一代你想往哪走？靠的是什麼？
2. 你家有沒有人走出了一條沒人規劃的路？
3. 上一代爬上去的東西，這一代還剩多少？

## 順序
- **第 7 輪**：
  - 文字排版；
  - 重點方向；
  - 身分網的骨架（資料格式、卡、在外面的家人）；
  - 先做「靠山」（大戶人家）、「法律」、「教會」三種力。
  - 原因：這三種在村裡就碰得到，而且最常互相接上。
- **第 8 輪**：戰爭、市鎮、婚姻（女繼承人和富寡婦）、時運（黑死病窗口），以及邊緣的路和換線交家。
