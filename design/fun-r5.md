# 第 5 輪計畫（第 4 輪 6 分之後）

報告：playtests/2026-10-17-fable-r4.md。最差的是三項：
- 看得懂 4
- 不是苦差事 4
- 有動力 5

三個診斷代理查出的根本原因有四個：
1. 錢是自動花掉的。每年收成前，家裡會自動買 90 天的糧，把錢花光，就算只剩一個月就收成也照買。米迦勒節同一天又是收成、還債、交租。前一刻才免了債，下一刻交不出的租又記成新債。
2. 人生大事不經過玩家。村民的「私通」計畫可以把玩家家主當對象，事後連家主一起記成有罪的一方。家人的私情只能靠每年 4% 到 8% 的機率被發現，所以七年都沒有一點風聲。
3. 每季能做的事，只有六種一模一樣的聊天。開口幾乎不會被拒絕：交情一高就加 60 分。好感也沒有衰退，全村最後都是 +100。
4. 志向的目標都是固定數字：有 3000 便士時，「存到 300」選下去的那一刻就完成了。到了第 4 階以後，就沒有下一個梯子可爬。

下面分四批，整體一起改。✓ = 已做。

## A 收成和米迦勒節：錢由你算
- 買糧：只買到收成那天為止。玩家家裡缺糧時先問你，有四個選項：
  - 買到收成（X 便士）；
  - 只買一個月；
  - 向鄰居借糧；
  - 勒緊褲帶。

  村民和自動過年照舊自動買，但會記一行花了多少。
- 買牛也先問你。
- 米迦勒節算總帳：交不出租的時候，先跳一張卡。
  - 卡上寫出租怎麼算的（地幾畝、身分、戰時加成）、欠多少、手上有多少錢，以及餘糧能賣多少錢。
  - 選項有六個：
    - 賣糧；
    - 退回幾畝地；
    - 賣牛；
    - 向某某借（寫出是誰、什麼條件）；
    - 求管家寬限；
    - 先記在帳上。
  - 舊債和新租放在一起算，免債或還清的那一年，交不出的租改成寬限一年。
- 私人借的債，到約定的米迦勒節才還，不再每個月扣錢。放債的對象改成缺錢的人家。
- 收支：
  - 「上一季的變化」把五便士以上的每一筆都列出來；
  - 手藝收入寫出是誰、做什麼手藝；
  - 地租變了會說為什麼（打仗、贖了身）。
- 錢的尺度：
  - 一家只有一個手藝人拿全薪（做家裡主業的那個；沒有主業，就是手藝最好的那個），其他人拿一半（審查後照程式改寫）；
  - 瘟疫後工錢漲，手藝只跟著漲一半；
  - 小地主要付僕人工錢和房屋的維修。

## B 你作主，藏著的事會浮上來
- 有人想跟家主私通，先問你：拒絕，或順水推舟。不答應就不會記到家主頭上。
- 家人自己的私情，要經過一條事件鏈：
  1. 先有風聲；
  2. 鄰居暗示，你可以追問、不理或盯著；
  3. 撞見，你可以對質、告到教會法庭、找他打一架或忍下來。
  - 這段期間出生的孩子會有「長得不像你」的疑心。
  - 情夫是領主的話，領主對你的好感不會再是滿分。
- 家人要開始追求、讀書、報仇或造謠，先問家主准不准。家人自己的計畫，記錄寫成「某某自己的……」，不再用你的口吻。
- 「由她自己拿主意」「不買了」改成安靜地取消，不再記成對方回絕、也不會傳遍全村。
- 換家主時，只要繼承人活著、當了家，進行中的計畫就交給他。已經自由了就說「不用贖了」。
- 同名的人：
  - 死了不久的、在外地的人也算同名；
  - 自家人用稱謂稱呼（「你的弟弟亞當」）；
  - 都分不出來時，加上出生年。
  - 秘密裡的犯人，照當年的年紀檢查合不合理。
- 小錯：
  - 「求見領主」只對真正的領主；
  - 攝政結束後恢復原來的職業；
  - 同一個人不會跳兩張喪偶卡，沒有孩子就不給「放在孩子身上」的選項；
  - 一個人不能同時當兩個差事；
  - 現任的人自動出來連任，落選一定記一行。
- 死亡要有分量：
  - 先病一兩個月，可以請人看病、請神父、多給吃的；
  - 在外地死的親人，消息會傳回家，兄弟姊妹也會傷心；
  - 喪偶的文字照死因、結婚多久、有沒有孩子來寫，再次喪偶有不同的話。

## C 每季的事、開口和人情
- ✓ 每季列出 2 到 4 件「這一季的事」，照家裡的情形給，例如：
  - ✓ 去市集賣糧；
  - ✓ 收成季雇短工；
  - ✓ 替餓著的親戚想長久的辦法：分幾畝地、接進門、雇他當長工；
  - ✓ 教孩子認字；
  - ✓ 去追求某人。

  ✓ 談心、上教堂、誇獎、帶去市集合成一件「陪家人」，自動找最需要陪的那個人。
- ✓ 開口會拒絕：
  - ✓ 交情最多加 25 分；
  - ✓ 賣了就不夠吃的地，不賣；
  - ✓ 對方自己也想要的東西，不給；
  - ✓ 對手、你家的名聲、對方想要什麼，都會算進去。
  - ✓ 大事（買地、說親）就算交情好，通常也會提條件，當場就問你答不答應。
  - ✓ 答應了也會說出顧慮，例如「好吧，不過兒子們不太高興」。
- ✓ 好感會淡：
  - ✓ 每種原因都有上限，越加越少；
  - ✓ 慢慢衰退，不會到期了一下子歸零；
  - ✓ 打架、私通、搶地、估稅會讓好感往下掉。
  - ✓ 「冷落過我 +6」改寫成「『冷落過我』的事淡了 +6」。
  - ✓ 家外親人的好感變化很大時，也會告訴你。
- ✓ 不重複：
  - ✓ 同一戶人家三年內不會再碰到同一件事或同一段插曲；
  - ✓ 每年都有的制度（例如國王的稅）至少要有三種寫法，還有不同的情形：輪到你當估稅人、去年藏過錢、照村裡的配額分攤、歉收時請求減稅。
- ✓ 親友挨餓：送了糧，家裡的人也真的吃飽；早一點來問；第二次以後就只給長久的辦法。
- ✓ 計畫：
  - ✓ 開計畫會寫出要用一段空閒；
  - ✓ 滿兩件時還是列出來，並說明要先放棄一件；
  - ✓ 「眼下辦不成」一定寫出原因。

## D 志向跟著家境走，還有後半場
- 選志向的時候，已經完成一半的志向排得很後面（權重四分之一），想接著做完也可以選（審查後照程式改寫）。
- 錢和地的目標，照選的時候手上有多少來算。祈唱壇照身分定價。選的時候顯示「已完成幾步」。
- 差事的條件全部列出來，每一條打 ✓ 或 ✗：
  - 欠債多少、上限多少；
  - 欠著領主的人情到哪一年；
  - 還要幾年才夠年紀。

  「求領主開恩」的選項寫明「從此 10 年選不上莊頭」。
- 後半場，新的志向：
  - 村裡第一大戶：要跟其他想擴地的人家搶地；
  - 和德·阿什科姆家結親：小地主的人家可以和領主家說親，會有別家的女兒來搶；
  - 莊園欠我家的錢：借給莊園一大筆，還不出來就拿自營地或磨坊來抵；
  - 十年莊頭：一家連任幾個差事，有對手的人家來搶。
