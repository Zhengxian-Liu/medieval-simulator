# 文字版的排版和顯示邏輯

狀態：設計，2026-10-19。使用者說「先不搞圖，先處理好文字信息排列和展示邏輯」。
依據是第 5 輪版本（1307d51，種子 64）的截圖，加上 Fable 第 5 輪的報告（「看得懂 5」）。
第 6 輪合併之後做，跟[重點方向](focus-paths.md)一起成為第 7 輪。網頁版（`tools/ui/index.html`）和文字版（`tools/ui/textplay.py`）照同一套規則。

## 現在的問題（看截圖）
1. **主次不分**：
   - 「發生的事」裡，卡、你的選擇、結果、買糧、村裡的消息、條件清單，都是同一種字。
   - 一季十幾行，真正的大事（女兒出生、借了 60 便士）埋在中間。
2. **同一件事說好幾遍**：
   - 「莊頭的條件」和「路怎麼走」在頂欄、記錄裡、志向卡上各出現一次。
   - 「村裡在說」一年裡有五行「某家在打北田那 5 畝的主意」。
3. **選擇和結果分開**：
   - 〔放債收利〕「選擇：借」在一行，「成功：收下 60 便士」在上面另一行。
   - 明年還錢時，也沒說這是哪一筆。
4. **家裡欄太長**：
   - 每個人都有五條需求條、特質、重心選單、人生路。
   - 0 歲的嬰兒跟家主佔一樣大。
5. **村裡在說**：
   - 全是陌生人的生孩子、結婚，沒有分出跟你有關係的。
   - 最舊的也一直留著。
6. **格式不一致**：
   - 括號有〔〕、【】、（）三種。
   - 數字有時候有單位，有時候沒有。
   - ✓/✗ 有時候寫了實際的數，有時候沒寫。

## 三層：什麼一直看得到，什麼要點開

**第一層：頂欄，一直在，兩行以內。**
- 第一行：家名、年季、地位、錢、存糧（天數，缺糧標紅）、地、欠債（欠誰、何時到期）、名聲。
- 第二行：志向和下一步，只寫最近的一個關卡，例如「志向：當莊頭；下一步 ✗ 欠債 75，上限 20」。
- 點開才看到全部條件和人生路。頂欄以外不再重複條件清單。

**第二層：中間，現在要你做決定的事。**
- 有卡時只放卡：
  - 先一句發生了什麼；
  - 再列選項，每個選項附它的代價和理由；
  - 沒解開的選項打 ✗ 並寫差什麼。
- 沒有卡時放「這一季」：
  - 這一季的事（最多 5 件，跟志向有關的放最前面）；
  - 剩幾段空閒；
  - 過這一季的按鈕。

**第三層：記錄和參考，要看才看。**
- 編年記錄（見下面），還有在爭什麼、地圖、關係網、村民、計畫。

## 編年記錄（取代「發生的事」和「近況」）

照季分段，每季最多三塊，新的在上面。

1. **大事**，粗體，每件一行，至少要有：
   - 家裡的生、死、婚嫁；
   - 你答過的卡；
   - 志向、方向走到新的一步；
   - 爭贏或爭輸；
   - 欠債或還清。
2. **選擇和結果放在同一條**：
   - 寫法：「〔放債收利〕向威廉·謝帕德借 60 便士 → 明年米迦勒節還 75」。
   - 結果晚到時，接在原條下面，並註明出處，例如「1331 秋：還清了（1330 春借的）」。
3. **這一季的帳**，一行，點開才看明細：
   - 例：「錢 0 → 60（打短工 +61、放債收入 +60；買糧 −53、衣服和鹽 −8）」。
   - 買糧合成一筆：「買糧 3 次，28 天，53 便士」。
4. **村裡的消息**，只在跟你家有關時才進大事：
   - 有關 = 親戚、好感 40 以上、對手、你想要的東西。
   - 其他的收成一行：「還有 7 則村裡的消息 ▸」。

心情變化（「從平靜變得高興」）不進記錄，放在那個人的名牌上。

## 家裡欄
- **預設每人兩行**：
  - 第一行：名字、稱呼、年紀、心情；
  - 第二行：他最想要的事、對你的好感。
  - 點開才看到需求條、特質、方向和人生路。
- **需求條**只在有一項掉到黃或紅時才露出來，也只露那一項。
- **5 歲以下的孩子**合成一行，例如「孩子：羅傑 4 歲、小蘿絲 0 歲」。
- **按鈕**：每個人最多兩個（★ 推薦的那個，加上「更多…」）。

## 村裡在說
- **同一件事合成一條**：
  - 例：「北田黑土東頭 5 畝：卡特、米勒、弗萊徹、里夫家都想要 → 1328 年讓里夫家拿到了」。
  - 爭的過程連到「在爭什麼」分頁。
- **排序**：跟你有關的放上面。陌生人生孩子、結婚，每年合成一行，例如「1329 年村裡生了 9 個孩子、2 對結婚 ▸」。
- **只留最近**：預設只留最近三年，其他收起來。

## 寫法的規矩（程式和資料都照這個）
- **數字一定帶單位**：便士、天、畝、歲。錢的變化寫「+61／−53」，後面括號寫原因。
- **✓/✗ 後面一定寫實際的數和門檻**：例如「✗ 欠債 75（上限 20）」「✓ 年紀 31（25–65）」。
- **括號只用兩種**：
  - 〔卡名〕：你答過的卡；
  - 【消息】：聽來的。
  - 其他的說明用一般的（）。
- **名字**：
  - 每季第一次出現寫全名，之後只寫名字；
  - 同名的照第 6 輪 A 的全村規則分清楚。
- **不寫空話**：每一行都要讓人知道發生了什麼、為什麼、或接下來會怎樣。
  - 「情形變了」這種話要換成真正的原因。

## 驗收
- 截同一局同一季的畫面，拿來和現在比。
- 再讓 Fable 只看畫面回答三個問題：
  1. 這一季最重要的事是什麼？
  2. 你家現在卡在哪？
  3. 錢花到哪去了？
- 三題都答對才算過。
