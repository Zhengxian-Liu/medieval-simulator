# 好玩在哪、不好玩在哪：從 Fable 三次試玩出發（2026-10-16）

根據：`reviews/fable-round4-playtest.md`、`reviews/fable-round5-playtest.md`，以及第六輪的回報。

## 一、Fable 覺得好玩的時刻，有什麼共同點

| 時刻 | 背後的設計原理 |
|---|---|
| 拒婚 → 酒館說閒話 → 舊帳 → 法庭 → 結怨 → 放火 → 神父調解 | **因果鏈**：每一步都是上一步的後果，玩家講得出「為什麼」。CK 最核心的快感就是事後回頭能把故事講出來。 |
| 早年「討好領主」，後來算總帳時領主免了債 | **延遲回報**：投資和收穫隔了好幾年，玩家會覺得「當年做對了」。 |
| 違背個性的選擇壓在心上（「硬著頭皮冒的險」） | **角色身分的張力**：最划算的選擇不一定是這個人會做的選擇。這是 CK3 壓力系統的精髓：讓玩家在「最優解」和「扮演角色」之間掙扎。 |
| 瘟疫後 30 便士接 10 畝地；違反《勞工法令》賺高工錢 | **歷史給的兩難**：選項都有代價，而且代價來自那個時代真實的規則。 |
| 結親化仇、從小的玩伴長大後來說親 | **舊人回來**：之前認識的人以新的身分出現。 |

**共同點**：好玩的都是**回聲**，也就是以前的選擇或關係在後來回來了。單一事件本身很少好玩。

## 二、不好玩的時刻，有什麼共同點

| 時刻 | 違反的原理 |
|---|---|
| 頭十年又窮又餓，什麼都做不了 | **沒有槓桿**：壓力只有在玩家有辦法反抗時才是張力，否則就是懲罰。（第五輪已改善，但開局還是太單調。） |
| 「過一年」時親事、收地、臨終自己發生了 | **大事不經過玩家**：玩家記得的是自己做過的決定，系統替他做的大事不會留下任何感覺。（大部分已改成會問。） |
| 領主的勞役永遠「照做」，孩子病了兩個選項差不多 | **無腦選擇**：Sid Meier 說的「有趣的決定」要同時有：看得到的利害、不確定的結果、會留下來的後果。三樣缺一樣，就是雜訊。 |
| 說親時不知道對方有幾畝地、幾歲 | **看不見利害**：沒有資訊的選擇等於擲骰子。（已加。） |
| 同一句「井邊的婦人不說話了」出現六次 | **重複稀釋**：同一句話第二次出現，玩家就不再讀了。 |

## 三、還沒碰到的根本問題

1. **玩家不知道自己這一代要幹嘛。** 現在的志向只是一行字（「多種幾畝地」），計畫選單和志向沒有接起來。CK 每個角色都有清楚的「這輩子想要什麼」，加上一條看得見的路。
2. **回聲是偶然的，不是設計出來的。** 好玩的因果鏈現在靠運氣才會出現。應該讓每個重大選擇都「掛一個鉤子」，保證以後有機會回來。
3. **家人只是背景。** GDD 說要「指派家人任務（他們可能反抗）」，這部分還沒做。窮的時候，派兒子去打短工、女兒去幫傭、老母親去顧孩子，正是 Sims 那半邊的樂趣。
4. **沒有「場景」。** 大事都是一行字。婚禮、葬禮、莊園法庭、收穫節應該是「重點日子」：時間變慢，可以跟人說話、做幾個小選擇。這也是 Unreal 畫面最值得花力氣的地方。

## 四、改進方向（給討論用）

**A. 一代人的目標骨架（建議先做）**
每代家主選一個大志向，例如當上莊頭、替全家贖身、把兒子送進教會、報父仇、擴到 30 畝。每個志向拆成 3–4 個看得見的里程碑，計畫選單把「推進目標」的計畫排在前面並標出來。完成後留下家族傳統，失敗則留下遺憾，傳給下一代。
→ 玩家每次打開選單都知道自己在往哪走；回聲也有了方向。

**B. 刻意的回聲**
每個重大選擇（拒婚、賴帳、告人、救人）都登記一個「將來」：3–15 年內，用當事人或他們的孩子回來。編年史和「家裡知道什麼」會標出「這件事還沒完」。
→ 把 Fable 最喜歡的因果鏈從偶然變成必然。

**C. 消滅無腦選擇**
規則：統計時，如果 AI 有超過 80% 的時候選同一個選項，這個事件就要重寫或改成不問。每個事件至少要有兩個都有代價的選項，最好其中一個合乎角色的個性，另一個划算。

**D. 指派家人（Sims 半邊）**
每季可以給每個大人派一件事：下田、打短工、幫傭、照顧病人、去市集、陪人喝酒（社交）。個性不合的人會抱怨或偷懶。窮的時候這就是槓桿；富的時候這就是經營的樂趣。

**E. 重點日子場景**
婚禮、葬禮、法庭、收穫節變成小場景：可以跟在場的人說一兩句話，做 2–3 個小選擇，影響好感和傳聞。先在文字版做，之後直接就是 Unreal 的畫面腳本。

**F. 同年出生者（2026-10-16 同意，來自《80億分の1》）**
追蹤村裡和家主同年出生的幾個孩子，一路跟到老。家族報告和每章結尾並列比較：誰還活著、誰家地多、誰當上莊頭、誰進了城。
→ 支柱一「選擇要有看得見的影響」最直接的鏡子：同樣的起點，差別全是選擇和運氣造成的。

**G. 每代家族紀錄卡（2026-10-16 同意）**
家主死時產出一張卡：綽號、生卒年、志向成敗、留下了什麼、最大的恩怨。可以分享。
→ 給每一代一個收尾，也是遊戲向外傳播的入口。
