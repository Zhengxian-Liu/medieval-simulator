# 從第一性原理重看設計：缺的是「縫合」（2026-10-21）

> 狀態：提案，等 Zhengxian 看過。起因：你說「遊戲設計很重要的要素是縫合，要縫得絲滑而且有深度，也就是組合式創新」。
> 根據：[first-principles.md](first-principles.md)、[ck3-why-fun.md](ck3-why-fun.md)、第 1–8 輪 Fable 報告（[playtests/](../playtests/)），以及這次對程式的清點。

## 一句話結論

我們借了很多好東西：CK3 的人情和槓桿、模擬市民的一家人、80 億分之一的人生路、莊園制度，可是它們是**並排掛著**，不是**縫在一起**。每個系統都自己收東西、自己出卡、自己給一個數字，系統之間很少互相餵。

所以每個部分單看都還行：中世紀味道、人生路都拿到 8 分，故事 7 分。可是加起來沒有相乘，最弱的那塊（吃飯這件苦差事）也沒有別的系統能救它。Fable 連三輪 6.5 分，原因就在這裡：每輪修的都是某一塊裡面的事，沒有動到塊和塊之間的接頭。

## 一、什麼叫縫得好

從縫得好的遊戲看，有六個特徵。每一條後面都寫了一個檢驗方法。

| 特徵 | 例子 | 檢驗 |
|---|---|---|
| **1. 一個動作，兩個意義** | 星露谷：種出來的作物既是錢，也是送人的禮。黑帝斯：死掉既是失敗，也是劇情往前走。 | 玩家每做一件事，能不能說出它同時推動了哪兩件事？ |
| **2. 一種東西流過所有系統** | CK3：金錢、威望、虔誠、把柄、好感，每個系統都收這些，也都吐這些。 | 每個系統產出的東西，有沒有別的系統要用？ |
| **3. 接頭上有取捨** | CK3：女兒嫁給盟友換來聯盟，嫁給有地的人換來繼承權，只有一個女兒。 | 同一樣稀少的東西，是不是至少有兩個系統在搶？ |
| **4. 一個對手串起所有戰場** | CK3 的宿敵：搶頭銜的是他，搶婚事的是他，暗殺的也是他。 | 這一代的對手，有沒有在三種以上的事情上碰到你？ |
| **5. 時間把系統擠在一起** | 星露谷的節日：送禮、比賽、約會同一天。 | 有沒有幾個日子，好幾個系統的期限撞在同一天？ |
| **6. 動詞少，對象多** | 薩爾達曠野之息的化學規則：火、風、金屬幾條規則，碰上什麼都有效果。 | 同一個動作能不能用在不同的人、不同的東西上，而且意思跟著處境變？ |

還有一個總檢驗：**拿掉這個系統，別的系統會不會壞？** 都不會壞的系統，就是掛上去的，不是縫進去的。

## 二、第一性原理：玩家在這個遊戲裡到底在做什麼

一句話：**用一家人有限的地、糧、人手，換成在村裡的位置，再交給下一代。**

拆開是一個環：

```
地＋人手 ──→ 糧、錢 ──→ 人情、臉面 ──→ 位子、親事、靠山 ──→ 孩子的路、更多的地 ──→ 下一代
   ↑                                                                         │
   └─────────────────────────────────────────────────────────────────────────┘
```

每個系統都應該站在這個環上的某一段，前一段餵它，它餵後一段。現在這個環在**「糧、錢 → 人情、臉面」那一段斷了**：

- 糧食的出路只有兩條：吃掉，或賣給沒有名字的糧商。缺糧時跟市場買，同樣沒有對方（`economy.cpp` 的 `kFarmGate`）。
- 所以收成好壞只決定「這一季要不要做苦工」，不會變成村裡的局勢。
- 位子、親事、名聲又由別的卡各自決定，跟家裡有多少糧、借過誰幾次沒什麼關係。

斷在這一段，所以種田變成作業，政治變成另一份作業，兩份作業並排擺著。

## 三、現在縫的狀況（清點）

| 借來的東西 | 我們的系統 | 接到哪裡 | 縫的程度 |
|---|---|---|---|
| CK3 的人情、槓桿 | 開口、人情債 | 接濟、借錢、讓地、投票會欠人情，開口時可以提起來 | **縫上了一半**：產生人情的來源有十幾處，可是一般的買賣、打零工、送糧都不產生人情 |
| CK3 的志向 | 志向（二十多種） | 只看自己的條件清單 | **掛著**：Fable 說「志向沒有抓手」，不知道要跟誰爭、找誰幫 |
| CK3 的名聲 | 名聲數字 | 十幾處加減，像是當選 +2、地租沒交齊 −2 | **掛著**：Fable 第 8 輪寫，名聲不好卡了 13 年，做好事一次只加 1–2 |
| 模擬市民的一家人 | 家人的想要、陪家人 | 好感 | **掛著**：大多只為了漲好感，Fable 抱怨「最近才陪過」的假選項 |
| 莊園經濟 | 收成、地租、買糧、打零工 | 只接到錢和存糧 | **斷著**：這就是苦差事的根 |
| 80 億分之一的人生路 | 孩子的出路 | 弓兵會寄錢回家，其他大多是一段自己的故事 | **縫上了一點**：孩子當了神父、行會師傅，家裡沒有因此多一根槓桿 |
| 村裡的位子 | 選舉、職位 | 好感、人情、投票。莊頭會濫用職權整人 | **縫得最好的之一** |
| 世仇 | 世仇、了結恩怨 | 拒婚、不賣地、賴帳都會結仇 | **縫得不錯**：起因來自別的系統，可是收尾大多是一張專門的卡 |
| 消息網 | 傳話、村裡在說 | 所有事都靠它傳 | **縫得最好**：它是真正的線 |
| 莊園法庭 | 告狀、陪審 | 債、世仇 | **縫上了一半**：陪審員就是鄰居這點還沒用上 |

另外，動詞太多：14 種找人互動、50 多種計畫、每季的差事清單、7 種開口，還有 200 多張事件卡。每個動詞多半只屬於一個系統，所以加內容是加法，不是乘法。

## 四、缺的東西（照重要性排）

### A. 每一筆交換都要有對方（最根本，也最省）
**原則**：村子裡的糧、錢、人手，每一筆進出都有一個具名的對方。沒有名字的糧商只在進城趕集時出現。

- **荒年**：你家有餘糧，就成了全村最有力的那一家。你可以：
  - 高價賣，拿錢趁別人急著賣時買地，這是中世紀村子真實的土地市場：荒年就是土地易手的年頭；
  - 借給人，換來人情，到選舉、法庭時討回來；
  - 白送，換臉面；
  - 囤著。
  同一場荒年，對窮的那一家就是另一個問題：跟誰開口借、拿什麼抵，地、孩子去幫傭，還是一個人情。
- **豐年**：餘糧可以辦麥酒會、婚宴、喪宴，換成臉面和人情。
- **打零工**：替誰做工，就跟誰熟一點。對方是你的對手時，你得低頭替他做。

這樣一來，缺糧不再是一張重複的「買糧」卡，而是**「跟誰開口」**的社交題。有糧也不再只是數字，而是**「拿它換什麼」**的政治題。苦差事和政治縫成同一件事。

### B. 兩種通用的貨幣：人情、臉面
- **人情**：已經有了，要變成主幹。每一筆有對方的交換都留下人情，雙向、有名字、會淡、可以傳給下一代。開口、選舉、法庭、說親都收人情。
- **臉面**：取代現在的名聲數字。臉面只從公開的事來：辦宴、捐教堂、守靈、在法庭上作證、當職位、出醜。它花在選舉、說親、陪審團的態度上。
  - 做一件公開的大事，就能有感地往上拉，不是一次加 1。
  - 也要能一次大跌：私情敗露、賴帳被告。
- 把柄已經有了，當第三種貨幣，不用改。

**檢驗**：每張卡的每個選項，都寫得出它換掉了哪種貨幣、換來哪種。全是「好 vs 壞」的選項就要改或砍。

### C. 一個動作兩個意義：選之前就看得到牽動哪裡
- 卡上每個選項後面寫出它還牽動什麼，例如「也牽動：莊頭選舉（羅傑會記得）、南田那 5 畝」。
- 事件設計改成在系統之間做取捨，例如：
  - 守靈那晚，正好是跟死者的兒子談那塊地的時候；
  - 說親的嫁妝用地付，就少了地，可是多了一家姻親。

### D. 一個對手串起所有戰場
- 每一代自動選出一戶**宿敵**：前情和這一代跟你家撞得最多的那一戶。地、位子、親事、法庭，他都會出現。
- 志向不再是一份清單，而是寫成**「跟誰搶什麼」**，例如「在柴契爾家之前拿下南田那 5 畝」。
- 對手會因為你的動作改變做法。宿敵也可能透過一樁婚事變成姻親，這就是最好的結局之一。

### E. 讓系統撞在一起的日子
中世紀的日曆本來就會把事擠在一起。把零散的卡收成幾個**大日子**：
- **米迦勒節**：交租、選莊頭、雇工、交入地費；
- **收割**：搶人手、撿麥穗、看收成；
- **莊園開庭日**：所有官司一起審，陪審員就是你的鄰居；
- **復活節、聖靈降臨節的教會麥酒會**：說親、辦宴、看臉面。

一年 4 到 6 個大日子，每個大日子好幾個系統同時要你決定，平常的日子讓家人自己過。這也直接回應 Fable 每輪都抱怨的「同樣的事一直來」。

### F. 動詞少，對象多
把 14 種互動、7 種開口和差事清單裡的社交項，收成大約 6 個通用動詞，對任何人都能用，意思由處境決定：

- **給**：糧、錢、地、人手
- **借**
- **求**：開口要東西
- **討**：叫回人情
- **許**：許諾、婚約、投票
- **揭**：揭發、威脅

例子：「給」用在荒年的鄰居身上是接濟，用在選舉前的對手家是拉票，用在神父身上是捐獻。內容從加法變成乘法。

### G. 孩子的路要回饋到家
人生路已經多樣（8 分），可是走出去的孩子沒變成家裡的槓桿。每個出路都該給家裡一根新的槓桿：
- 當神父的兒子：教會的靠山、讀得懂文書、法庭上替家裡說話；
- 進城的兒子：城裡的價錢、借貸、替弟弟找師傅；
- 當護衛、弓兵的兒子：領主面前說得上話；
- 嫁出去的女兒：一整家姻親的人情。

這就是 80 億分之一的人生路和 CK3 的家族政治縫在一起的地方：**孩子的路就是家族的手牌。**

## 五、要降級或砍的

- **跟市場買糧**：村內的交換都要有對方。市場只留在進城趕集和城裡的價錢上。
- **名聲數字**：由臉面取代。
- **只為漲好感的互動**：談心、誇獎、喝酒。併進「給、求」，或者只在家人有事時才出。
- **志向的檢查清單**：改成「跟誰搶什麼」。
- **零散的月份卡**：大多收進大日子。

## 六、怎麼驗收

1. **接頭表**：每個系統一行，寫出它收什麼、吐什麼。吐出的東西沒有別的系統要用的，就改或砍。
2. **拿掉測試**：隨便拿掉一個系統，至少要有兩個別的系統變得不好玩。
3. **試玩時問一個問題**：「這一年最難的決定是什麼？它牽動了幾件事？」要答得出兩件以上，而且是不同系統的。
4. **苦差事**：任何重複的決定，都要舉得出一個「這次該反著做」的處境。

## 七、建議的順序（不加新系統，是重新接線）

1. **先做 A＋B**：交換都有對方，人情和臉面成為通用貨幣。
   - 這兩件同時解決苦差事的根（吃飯變成社交題）和名聲卡死的問題。
   - 要改的地方集中在經濟、開口、名聲，大約是一輪的量。
2. **再做 D＋E**：宿敵和大日子。這兩件讓「有動力」和「看得懂」上去。
3. **最後 C、F、G**：選項標出牽動、動詞收斂、孩子變成手牌。這些是把已有的內容重新接線，可以一批一批做。

每一步都用第六節的驗收方法檢查，再決定要不要請 Fable 打分。
