# 方向草案：村子裡的《行會》，加上 CK 的人（2026-10-16）

> 狀態：**只是其中一個玩法選項，玩法還沒定。** Zhengxian 說「《行會》很接近」指的是美術風格，不是玩法（2026-10-16），這份是誤會之下寫的，保留作為討論材料。來源：本串討論（「CK3 平民版」「為什麼模擬市民好玩」「世界觀太小、整天種田」），以及 [competitors.md](competitors.md)、[fun-analysis.md](fun-analysis.md)。

## 一句話

你是一戶平民。在一個村子和附近的市鎮裡，你靠手藝、生意、官位和手段讓家族往上爬，跟幾戶對手人家搶同一批位子，一代傳一代。村裡每個人都有自己的盤算，會記仇，也會報恩。

## 為什麼現在不好玩（本串討論的結論）

1. **大家都在種田**，玩家能做的事也大多是種田，所以故事沒有轉彎的地方。
2. **沒有對手**：一百個村民大多只是一個看法數字，沒有人跟你搶東西。
3. **短線是空的**：做一件事要等一季才看到結果，結果只是一行字。
4. **外面的世界不進來，人也出不去。**

## 從《行會》拿什麼

| 拿 | 在我們這裡長什麼樣 |
|---|---|
| **職業起家** | 開局不只有農夫，也可以是磨坊主、鐵匠、釀酒婦、織工、小販。每種職業有自己的生意、對手和往上的路（資料已有 occupations.json，要讓它變成玩法）。 |
| **很多條往上爬的路** | 錢（買地、開作坊）、官（村：品酒官、十戶長、莊頭；鎮：行會師傅、市議員）、教會、婚姻、使壞。志向（ambitions.json）掛在這些路上。 |
| **對手家族** | 每一代自動長出一兩戶跟你搶同一個位子的人家：同行、同樣想當莊頭、看上同一塊地或同一個姑娘。恩怨、計謀、法庭、消息網都圍著這場競爭轉。 |
| **手段** | 合法的（告上莊園法庭、拉票、送禮、聯姻）和不合法的（賄賂、散謠、雇人鬧事、偷偷壓價、放火）。被揭穿會有後果，已經有的計謀和法庭系統直接接上。 |
| **爭位的時刻** | 選莊頭、行會升師傅、法庭判決做成「重點日子」：時間放慢，可以拉票、交換條件、在最後一刻出手。 |

## 不拿什麼（《行會》被罵的地方）

- 不管貨車和庫存。生意是粗的：一季一兩個決定（擴不擴、壓不壓價、雇不雇人）。
- 不做整面表格。資訊用人話講，繼續用瀏覽器版那種卡片。
- 隨機壞事一定給玩家應對：事前能防，事後能反擊或求人。

## 從 CK 和模擬市民保留什麼

- 人做深：每個村民都由規則加模型決定，有記憶、有性格、有自己的盤算（已做）。
- 家族傳承、每代志向、性格壓力（已做一部分）。
- 消息網：誰知道你做了什麼，是一條條傳開的（已做）。
- 短線要補：每次互動馬上看到對方的反應和一個會累積的東西（好感、把柄、人情債）。

## 世界多大

- **家**：一個村子加莊園，約一百人，人在這裡做深。
- **市鎮**：半天路程。市集、行會、學徒、法庭上訴；農奴逃進城住滿一年又一天就自由了。先做成「出村」的場景和事件，不做完整地圖。
- **往外的門**：打仗（1337 年起徵弓箭手）、教會（送兒子當神父、朝聖）、進領主家當差、落草為寇。走出去的人可能回來，帶著錢、傷疤或仇人。
- **打進來的事**：收稅、徵兵、1348 年黑死病、貨郎和陌生人、換了新領主、1381 年農民起義（歷史時間軸已有，要讓它打到玩家身上）。

## 建議的順序

1. **對手家族 + 村裡的官位梯子 + 職業起家**，只在村子裡。這一步最能直接回答「好玩在哪」。
2. **市鎮**：行會、學徒、市議會。商人出身從這裡開放。
3. **往外的門**：戰爭、教會、當差、落草。

## 要你決定的

- 開局還是在村子（建議），還是直接放進市鎮、更接近《行會》？
- 「使壞」的尺度：只到賄賂、散謠、告人、放火，還是包括下毒、雇兇殺人？
