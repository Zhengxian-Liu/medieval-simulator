# 從第一性原理重想玩法，並體檢現有系統（2026-10-16）

> 狀態：提案，等 Zhengxian 看過。整理自本串討論，以及 [ck3-why-fun.md](ck3-why-fun.md)、[competitors.md](competitors.md)、[fun-analysis.md](fun-analysis.md)。取代 [direction-guild.md](direction-guild.md) 那份誤會之下寫的草案。

## 一、玩家要的四件事，和怎樣算做到

| 要求 | 意思 | 檢驗 |
|---|---|---|
| **真實的中世紀** | 玩家煩惱的，就是當時的人煩惱的：熬過冬天、討好領主、替兒女說好親事、在村裡抬得起頭、死後靈魂得救 | 玩完一代，能說出「原來那時候的人是這樣過日子的」 |
| **世界是活的** | 你什麼都不做，事情照樣發生，而且每件事都有原因 | 放著五年不管，回來時村裡的局勢變了，而且看得懂為什麼 |
| **行為有影響力** | 你做的事會留在世界上，看得出是你做的 | 一代結束時，能指著村裡幾件事說「這是因為我」 |
| **有深度，不是作業** | 重複出現的決定，每次答案都可能不同，因為處境不同 | 任何重複的事，都舉得出一個「這次該反著做」的情況；舉不出來的就是作業，要嘛自動化，要嘛砍掉 |

## 二、推出來的五條原理

### 原理 1：人人追求自己的目的，搶的是同一批有限的東西
危機不是發給玩家的。每戶人家的基本驅動都差不多：讓家撐下去、把地守住傳給孩子、往上爬一點、在村裡抬得起頭。真正會撞起來的，是那些有限的東西：

- **地**：村裡的地就那麼多，誰家多一畝，就是誰家少一畝。
- **位子**：莊頭、品酒官、教堂執事，都只有一個。
- **親事**：門當戶對的兒女，就那幾個。
- **領主的偏愛和人情**。
- **生意**：兩個鐵匠搶同一村的客人。
- **荒年的糧食**。

沒有人是在針對你，但他們在追求自己目的時就撞到了你，你非應對不可。天生的關係（親戚、教父母、鄰居、同年長大的玩伴）是人和人之間的基礎設定，決定誰天生是盟友。

### 原理 2：好感是手段，不是目的
玩法的核心句型是：**「我想要 X，X 在 Y 手上（或 Y 能決定），我用哪根槓桿讓 Y 照我的意思做？」**

中世紀村子裡真實存在的槓桿：
- 好感和交情
- **人情債**：上次他家蓋房你去幫了忙
- 血緣和姻親
- 錢和借貸
- 把柄和秘密
- 莊園法庭和習慣法
- 領主
- 神父
- 村裡的輿論：陪審團就是鄰居
- 威脅和暴力

哪根槓桿最好用，取決於對方的性格、你們的關係和你當下的處境。所以同一個決定每次答案都不同，這就是深度。

### 原理 3：Stake 來自「會失去的東西＋對手＋期限」，而且是自然長出來的
人生本身就會製造期限，不需要編劇：
- **父親死**：要交最好的牲口給領主，還要付入地費，付不出來，地可能租給別家。
- **女兒到了年紀**：好人家很快就會被別人訂走。
- **莊頭三年一選。**
- **荒年的冬天。**
- **領主換人**：新領主可能更狠。
- **兄弟分家。**

再加上原理 1 的對手，stake 就有了。失敗的代價要真的留下來，並且傳給下一代。

### 原理 4：看得見
玩家要看得到別人想要什麼、誰盯著哪塊地、誰家在替兒子物色哪個姑娘。CK3 自己被罵的一點，就是很難知道別人最近在做什麼，所以很難在乎他們。也要看得到因果，例如「因為五年前你拒了他家的親」。

### 原理 5：事會回來，人會變
重大的事會在幾年後以當事人或他們的孩子回來（刻意的回聲）。人在一生中會變：受傷、染上惡習、變得憤世嫉俗、得到綽號。

## 三、現有系統體檢

判斷：**留下**（已經符合原理）、**加深**（方向對，但不夠）、**改**（要換掉做法）、**砍**（作業，自動化或拿掉）。

| 系統 | 判斷 | 為什麼 | 怎麼做 |
|---|---|---|---|
| 好感＝相性＋記憶，附原因 | 留下 | 是所有槓桿的基礎 | 不變 |
| 恩怨、世仇傳一半給子女 | 留下 | 延遲後果的骨幹 | 讓恩怨更常從「搶同一樣東西」裡長出來 |
| 事實層和信念層、傳聞、打聽 | 留下 | 秘密就是貨幣 | 不變 |
| 把柄、勒索、揭發 | 加深 | 是好槓桿，但玩家很少有非用不可的目的 | 接到原理 2 的「我想要 X」上 |
| 消息網（熟識、傳話） | 留下 | 世界是活的、看得見 | 也拿來傳「誰想要什麼」 |
| 莊園法庭和陪審 | 加深 | 是搶東西的戰場，鄰居就是陪審 | 做成重點日子：開庭前可以拉人、求人、威脅證人 |
| 莊頭選舉 | 加深 | 有限的位子，三年一次的期限 | 同上，加上候選人各自的盤算 |
| 欠債的連鎖 | 留下 | 自然的危機，也有期限 | 不變 |
| 莊園制度（婚姻稅、死後稅、勞役、贖身） | 加深 | 真實，也是期限的來源 | 死後稅和入地費要真的可能讓家失去地 |
| 繼承、臨終床前 | 加深 | 死亡應該是心跳 | 換家主時：入地費、兄弟分家、寡婦產、對手趁機出手 |
| 壓力和崩潰 | 加深 | 代價太輕 | 崩潰留下會改變人的特質（酗酒、易怒、虔誠到出家） |
| 人心（NPC 年度盤算） | 加深 | 已經有，但多半是顧自己或報私仇 | 盤算要指向具體的有限東西，而且會互相撞 |
| 志向（20 種） | **改** | 多是抽象的自我提升，不做也不會失去什麼 | 換成具體、有人搶的東西，例如「弗萊徹家那 5 畝地」「替長子娶到米勒家的女兒」「下一任莊頭」，從處境裡自然長出來 |
| 家族階梯 | 加深 | 方向對 | 每往上一階，就換一批新的槓桿和新的對手（自耕農能上法庭告領主的管家，小地主能雇人） |
| 找人互動（14 種，例如談心、誇獎、喝酒） | **改** | 現在大多為了漲好感，這是「做作業」感最大的來源 | 改成「開口要東西」：請他投票、借錢、作證、把女兒許給你家、讓出那塊地；漲好感只是鋪路 |
| 家人的想要 | 留下 | 家裡的小戲 | 確認同一種想要不會總是同一個答案 |
| 計畫（40 多種） | 加深 | 槓桿很多 | 按「你想要的東西」排序，標出每個計畫是對誰、為了什麼 |
| 開局處境（幾種寫好的開場） | **改** | 你說得對，危機不該是發的 | 開局前先讓村子自己跑 20–30 年，恩怨、欠債、親事、誰盯著誰都是跑出來的 |
| 事件（約 70 個） | 加深＋砍 | 有些只推好感數字，或總是同一個答案 | 每個事件都要留下將來（一筆人情、一個把柄、一段恩怨），或者改變誰手上有什麼；做不到就砍 |
| 五項需求 | **砍成背景** | 照顧需求的決定大多是固定答案 | 家人自己照顧自己，只有出問題時才浮上來（挨凍、病倒、心裡苦） |
| 經濟（收成、地租、零工） | 留下當賭注 | 種田不是玩法，是賭注 | 玩家不必天天操作，但要修好「到第三代就太有錢」：一富 stake 就沒了 |
| 季節時間（每季幾段空閒） | 加深 | 時間有限是好的取捨 | 空閒用在「為了某樣東西去找某個人」上 |
| 歷史時間軸 | 加深 | 真實，也該打亂有限的東西 | 黑死病之後空出大量的地，全村搶地；饑荒時搶糧 |
| 傳家之物、編年史、綽號 | 留下 | 讓人被記住 | 不變 |
| 瀏覽器試玩介面 | 加深 | 已經清楚 | 加一欄「村裡誰想要什麼」：哪塊地、哪個位子、哪門親事，誰在盯著 |

## 四、要新增的

1. **有限東西的帳本**：每塊地是誰的、每個位子是誰的、誰家有適婚的兒女。這是原理 1 的地基。
2. **人人的「想要」都指向帳本上的東西**：NPC 的盤算會撞在一起，而且玩家看得見。
3. **人情債**：幫過誰、欠過誰，是中世紀村子最真實的貨幣，也是一根新的槓桿。
4. **開局前先跑歷史**：讓危機自然存在，不用發。

## 五、建議的順序

1. **有限東西的帳本、互撞的盤算、看得見，再加上「開口要東西」的互動。** 這一步直接回答「好感是手段」和「危機自然存在」。
2. **繼承當心跳，加上開局前先跑歷史。**
3. **事件體檢**（砍掉只推數字的）**和刻意的回聲。**
4. **人會變**（傷疤、惡習、綽號），**加上重點日子**（法庭、選舉、婚禮、葬禮）。

## 六、要你決定的

- 這五條原理對不對？有沒有漏掉的？
- 五項需求「砍成背景」可以嗎？還是你希望保留一部分模擬市民那種照顧小人的感覺？
