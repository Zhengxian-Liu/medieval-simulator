# 回應第二輪（Fable）

收到「買到收成改不掉」是 bug 且已修（24ab942）。那麼 r8 真正剩下的是：某些種子下一個普通年份在自己的地上活不下來（1331–1344 錢 0 糧 0）。步驟 0 就是校準加底錢，同意。

## 1–5 的回答

1. **B：同意，加一個條件。** 名聲只從**公開、而且村裡傳開了**的事動：荒年白送（+，幅度要像一件大事，不是 +1）、三倍價賣（−，乘人之危）、借（0，只留人情）。借是私事，所以不動名聲，這樣人情和名聲才分得開。另外把「領救濟 −1」改成「濟貧箱 −1」：排在寡婦後面是公開的，領親戚的糧不是。這樣名聲的來源就全在 A 的卡上，不另修。
2. **米迦勒節。** 同意你的理由：開票前看到誰偏向誰，比位子動詞更直接救「有動力」和「看得懂」。位子動詞排下一輪，跟 G 一起。這輪只在米迦勒節畫面加一行「你當看籬人這一年：…」，讓位子至少有存在感，不加決定。
3. **一行一個選項夠，但有四個硬條件：**
   - 選項 ≤ 4（三戶＋糧商），有餘糧時 ≤ 4（賣／借／送／囤）；
   - 「他要什麼」寫具體的東西：「30 便士」「亨利去幫傭三年」「秋天那一票」，不寫「一個人情」；
   - 「也牽動」最多兩項，寫名字和事，不寫數字：「柴契爾會記得｜南田 5 畝」；
   - 選完**立刻**在當季帳上出現一行，數字不能在下一個提示才變。
   頂欄只要兩個數字：存糧天數 vs 到秋收天數、手上的錢。看得懂的風險不在這張卡，在事後的帳。
4. **併進 D，但分兩半。** 「宿敵趁你弱時出手」（喪事、荒年、欠債時搶你的租地、壓價）歸 D。但「死亡的代價要看得見」歸 C 的「大事推到最上面」：r8 耕牛被扣抵死後稅只在訃聞裡出現，這不是對手的問題，是呈現的問題。兩半都做，不需要獨立項目。
5. **新的 Fable，沒讀過任何設計文件。** 十一個問題在玩完之後才給，不是之前。種子用 r8 那個窮種子加一個新種子，否則步驟 0 的校準沒被測到。使用者自己玩一局當第二個樣本最便宜也最準，兩者都做最好。

## 交給建置者的順序

0. **校準與地基**：10 畝、6–8 口的普通年份在自己的地上活得下去；「買到收成」保留一年地租＋入地費的底錢；「賣餘糧」「拿錢還債」常駐；同一張卡同一代文字相同最多兩次；辦不成的「陪伴」不列出。
1. **A（只做糧）**：缺糧→卡列 ≤3 戶具名人家（從債務、盤算、好感、宿敵裡挑）＋糧商（貴、無人情）；荒年有餘糧→誰來求，賣／借／送／囤。每筆寫一行人情（名字＋原因）。名聲只由公開的送與三倍價賣動，借不動。
2. **D（縮小）**：每代選撞得最多的一戶當宿敵；頂欄一行「他在跟你搶：…」；志向改寫成「在 X 之前拿到 Y」；A 的卡優先讓他當對方；他在你弱時（喪事、荒年、欠債）出手一次：入地費到期時出價租你的地、壓價。
3. **C（只做新卡）**：一行一個選項「對方｜他要什麼｜也牽動」；代價寫在選前；大事（選上位子、死後稅扣牛、債變動、家人出入）推到最上面。
4. **米迦勒節一個畫面**：地租、入地費、債主算帳、開票前的「誰偏向誰、為什麼」、交換提議（免債換票）；若當職位，加一行這一年的位子。
5. **驗收**：新 Fable 玩 15 年（r8 種子＋一個新種子），玩完回答十一題；使用者玩一局當對照。
