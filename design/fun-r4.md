# 第 4 輪計畫（第 3 輪 5.5 分之後）

報告：playtests/2026-10-17-fable-r3.md。拖垮整體的是三件事：
1. 錢在第一年就沒有意義了。
2. 玩家碰不到自己最在乎的事：親人挨餓、借錢、兒女婚嫁。
3. 三分之一的季節沒有事可做。

下面分五批，整體一起改。✓ = 已做。

## A 錢要緊
- ✓ 賣糧照糧販的出價算，是市價的六成。
- ✓ 照家族身分花用：自耕農每月最多 22 便士，小地主每月最多 40 便士。
- ✓ 國王的十五分之一稅：從 1332 年起偶爾有，打仗那幾年每年七成機會。家當不到 120 便士的人家免稅。玩家家要選：
  - 照實交；
  - 埋錢只報一半（被查到要補交，另外罰款）；
  - 塞錢給估稅的鄰居（記成一條秘密）。
- ✓ 嫁妝照身分：不到自耕農 100 便士，自耕農 240 便士，小地主 480 便士。
- 抽查結果：種子 58 開局的錢從 2347 降到 183，35 年後約 5000。餓死的人數沒有變多。

## B 家裡的事你作主
- ✓ 別家替兒子向你家女兒說親，一定先問你（答應或回絕），回絕後兩年不再來問。
- ✓ 老兵再出征、娶寡婦、走書記的路，都由家長決定。
- ✓ 有人來借錢、而你家是村裡最有錢的人家時，問你：借、借但要多還兩成、白送、不借。不借就換下一家去借。
- ✓ 別人欠你家的債到期了，問你：上門討（或告上法庭）、再寬限一年、免了。
- ✓ 換人當家時，老家主手上沒辦完的計畫交給新家主接著辦；接不了就寫出來。
- ✓ 親人或好朋友家快斷糧時跳一張卡：送三個月的糧、送錢買糧、免債、先不管。
- ✓ 可以對任何一戶人家用：送糧、借錢、免債。
- ✓ 每戶人家都會記下「今年缺糧」。
- ✓ 「趕緊另說一門親」真的開一門說親；說親開不出來時寫出為什麼，兒女的等待也先停著不算。

## C 每季都有事做
- ✓ 家主可以同時進行兩件計畫。
- ✓ 計畫的冷卻：
  - 只有失敗才整段冷卻，辦成了一年內就能再辦；
  - 買地、買自由地、包租、結交、找靠山改成冷卻一年；
  - 買地的上限放寬到 120 畝。
- ✓ 新的長期計畫：
  - 包下磨坊：押金 120 便士，每年交莊園 45 便士，收全村的磨麥錢，村裡人會嫌抽得重；
  - 放債收利：借 60 收 75，虔誠的人心裡不安；
  - 給小兒子分家置產：成了親、不是長子的兒子帶妻兒自立門戶；
  - 跟鎮上人家結親：女兒嫁進鎮上，家裡從此在鎮上有親家。
- ✓ 開不了的計畫寫出原因，以及「還要 N 季」。
- ✓ 差事：
  - 看籬人可以讓家裡其他男人出來選；
  - 沒選上，這個願望還在，下回接著爭，也可以放下；
  - 開票一定寫出票數，沒人爭也說；
  - 平手時現任的連任，不然由老爺點名，並寫明。
  - 「好幾家都想要」的消息不再跟「當上了」重複。

## D 志向講真話
- ✓ 立志時列出整條路，最後一步也有名字，並寫怎麼推進、哪些計畫有用。
- ✓ 每個月檢查；達成當月就算數。每一步照現在的情形顯示：做到過、後來又不夠了，標成 △。
- ✓ 「孩子」也算孫子和在外地的孩子。
- ✓ 路走不通時（例如沒有兒子了、自營地包給了別人）當場寫【志向受挫】，並讓玩家重新立志。
- ✓ 只剩一個志向可選時也問；也可以「先不立志，明年再說」。

## E 不重複，結果照實際情形
- ✓ 對方正希望的那件事，做了就一定成功；沒空的時候不標 ★。對方冷淡時寫出原因（好感低、心情差、脾氣）。
- ✓ 卡片：
  - 帳本、派勞役、收租、莊園要用錢都多了幾種說法，冷卻拉長；
  - 「莊園要用錢」不再寫死「替女兒備嫁妝」；
  - 勞工法令只發給地少、靠工錢的人家；
  - 家人想接濟朋友，兩年最多問一次，沒挨餓的人家不再寫「日子難過」。
- ✓ 喪子：兩年內又喪子時，改成一句安靜的話。
- ✓ 閒聊：綁年齡和身分；同一戶人家五年內不會再聽到同一句。
- ✓ 領主、神父不會來幫你割麥；朝聖寫出效果；被扒走的錢照身上的錢算。
- ✓ 開口時先送了禮、對方提條件，還可以答應條件。
- ✓ 按鈕顯示後情形變了（例如守靈讓全家的傷心淡了），會寫「用不著安慰了」，不再只說「不合適」。

## F 報告第 4 節的錯誤（三個診斷代理找出的原因）
- 同名的人改了稱呼，看起來像死人還在動。
- 領主的兒子到你家幫傭。
- 跟自己的父親「成了好朋友」。
- 別人搶地的出價寫進了你家的帳。
- 地塊名稱重複（「那 3 畝那 3 畝」），分割後的地塊名字不對。
- 喪事通知用的姓和下葬那天用的姓不一樣。
- 人生路只剩一句「黑死病」。
- 一歲的孩子當家死了，地卻歸到你家。
- 你家想要自己的地。
- 新婚妻子問起前夫的遺言。
- 替兒子說親，卻要你家出嫁妝。
- 收好處被記成做假帳，而且告解以後還列在秘密裡。
- 好感淡掉時寫成相反的理由。
- 開票平手沒有解釋。
- 僕人顯示主人家的 180 畝地。
- 未婚少女被叫「主婦」。
- 「祖母伊莎貝爾說」「老伊迪絲」這類稱呼不對。
