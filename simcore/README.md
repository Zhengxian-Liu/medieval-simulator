# SimCore（文字版原型）

Medieval Simulator 的模擬核心：標準 C++20 + CMake，不依賴 Unreal。設計見 `../design/GDD.md`、`../design/architecture.md`。

## 試玩與測試（一行指令）

需要：Mac 上裝好 Xcode 命令列工具（`xcode-select --install`）和 Python 3。有 CMake 會用 CMake，沒有也能編。

- 試玩：`bash scripts/play.sh`（隨機種子）或 `bash scripts/play.sh --seed 7`。第一次會先編譯，約 1 分鐘。設定 `export OPENROUTER_API_KEY=金鑰` 後，村民由決策模型決定；沒設就由規則決定。每局記錄存在 `saves/`。
- 測試：`bash scripts/test.sh`。先確認腳本在 Mac 內建的 bash 3.2 下能跑，再跑單元測試、模型局記錄能逐字重播、模型連不上時退回規則；不用網路也不用金鑰。改完任何東西都要先跑這個。
- 只編譯：`bash scripts/build.sh`。
- GitHub 建好 repo 後，`.github/workflows/test.yml` 會在 Linux 和 Mac 上自動跑 `scripts/test.sh`（Mac 上用內建的 /bin/bash 3.2）。

## 建置與執行

```sh
cmake -S . -B build && cmake --build build -j
./build/simcore_tests                       # 可決定性與不變量測試（約 1 分鐘）
./build/chronicle --seed 3 --start 1330 --years 100 --out chronicle.md
./build/stats --seeds 200 --threads 4 --out stats.md   # 跑很多局，統計存活率、節奏、事件次數
./build/play --seed 6 --start 1340                    # 自己當家主玩（互動文字模式）
```

### 自己玩（`play`）

每過一季停下來一次，先列上一季變了什麼（心情、誰對你的好感、錢花去哪、存糧），再列家裡每個人的心情、心事和想要你做的事，還有這一季剩幾段空閒（春 3、夏 2、秋 1、冬 2）。`t` 找人：挑家人或認識的人，安慰、談心、管教、請喝酒、送禮、求助、道歉、弔唁、找神父或領主……（`data/events/interactions.json`），每件花一段空閒，對方依個性、心情和對你的感覺回應；沒用掉的空閒算埋頭幹活，收成多一點。喪親、婚事、受欺負會在人心裡留下心事（`data/concerns.json`），讓心情變差、幹活變少，也會長出後續事件（`data/events/mourning.json`）。Enter 過一季、`y` 過一年、`k` 看「家裡知道什麼」（對各家的好感和原因、領主的態度、世仇、欠債、認定的秘密、還在追查的懸案）、`i` 細看一個人、`p` 定計畫（結交、討好領主、打聽、勒索、說親、報復……）、`c` 放棄計畫、`q` 結束。家主遇到要做決定的事件時會停下來，先說明情況再列出選項；輸入 `a` 交給 AI，`k` 先查再決定。輸入可以用管線餵；輸入用完之後 AI 接手玩到最後，`--out` 存一份紀錄。市集日這類例行小事不會問你（事件設 `"ask": false`）；每個事件可以用 `"prompt"` 寫抉擇前的情境。標了價錢、錢又不夠的選項會顯示成「（錢不夠）」不能選。村裡有人來向你的孩子（或女家主本人）說親、求親，都會先問你，並附上對方年紀、田地和你對他們的好感。家主年幼時由母親（或家裡最年長的大人）代為決定；年幼孩子的事、未婚孩子的親事（`"parent_decides": true`）也由家主決定。計畫選單會列出「現在還做不到的」計畫和條件，選對象時會看到年紀、雙方好感、田地、缺糧、欠債、世仇。

`--stop`：輸入用完就停下來。同一個種子加同樣的回答一定重演同一局，所以腳本或代理可以每次多加一個回答重跑，一路玩下去（Fable 的試玩就是這樣做的，見 `../design/reviews/fable-round4-playtest.md`）。

`chronicle` 參數：`--seed N`、`--start 1300..1380`、`--years N`、`--gentle`（溫和模式）、`--origin peasant|artisan|noble`、`--village`（連村裡的事也列出來）、`--out 檔案`。

## 目前有什麼

- 粗步進（每天一步）：五項需求、健康、死亡、懷孕生產、成長、技能、婚配、分家、繼承（長子 → 孫 → 長女 → 兄弟 → 遺孀）。
- 經濟：田畝收成、雇工、打零工、工匠收入、買糧、柴火、地租。
- 人際：好感＝天生相性＋記憶。重要的事記成行為紀錄（`data/deeds.json`：拒婚、法庭相告、燒麥垛……），每個相關的人留下會淡忘的記憶；重大恩怨在死時以一半強度傳給子女，並延及對方整個家族。「記仇」「寬厚」特質改變淡忘速度。秘密行為的受害者不知道是誰做的。
- 知情與傳聞：秘密行為只有做的人知道，偶爾有目擊者（可能認錯人），虔誠的人會去告解。知道的人會在村裡傳話，每傳一次就更不確定，也可能傳錯人。受害的一家相信了之後會記恨「他們以為的」兇手，可能告上莊園法庭；法庭可能判對、查無實據、判誣告，也可能冤枉好人，而領主家的人永遠告不倒。家主可以發起「打聽」計畫，聽到的不一定是真的（`src/knowledge.cpp`）。
- 訊號與延遲事件：事件可以掛在某件事之後幾個月才發生，例如良心不安、被拒婚之後、寡婦被催著再嫁（`src/signals.cpp`、`data/events/consequences.json`）。編年史結尾有「家裡相信的秘密，對照事實」。
- 莊園制度：自由民／農奴、婚姻稅、死後稅、勞役、什一稅、贖身、送孩子去幫傭、逃到鎮上（`src/manor.cpp`、`data/events/manor.json`）。
- 連鎖事件：`data/events/legacy.json` 依記憶挑對象（舊帳、仇家的孩子、當年的情分、刁難）。每筆行為紀錄記著起因，編年史結尾列出最長的恩怨鏈（開發用，包含秘密）。
- 壓力（仿 CK3）：做違背本性的選擇、喪親、挨餓、欠債、被人害都會累積壓力；過了 40／70／100 會崩潰，崩潰的方式看個性（喝酒、告解、對家人發火、朝聖……），每種都留下痕跡（`src/stress.cpp`、`data/events/stress.json`）。
- 長線故事：
  - 世仇：兩家的恩怨累積成嫌隙 → 結怨 → 世仇，每年慢慢淡去；秘密的事要等受害家「認定」了兇手才算，所以可能和錯的那家結仇。神父調解、結親化仇、仇家作梗、市集鬥毆（`src/arcs.cpp`、`data/events/arcs.json`）。
  - 欠債：交不出地租就欠著，第一年管家來催，第二年牽牛或拿傳家之物，第三年算總帳：交出幾畝地、替莊園服三年勞役、收房客、把地交回去當茅舍農，或求領主開恩（從此欠他人情，十年內選不上莊頭）。荒年不逼債。也能向鄰居借錢、讓孩子去幹活抵債；喝酒賒帳會欠酒館老闆娘的錢。匠人家沒人掌鋪時，鋪子租給幫工，兒子長大再接手。
  - 情人：一對情人只算一件秘密，每年可能淡掉、被配偶察覺或鬧成醜聞。
- 把柄（仿 CK）：相信自己知道別人的秘密就有了把柄，可以要錢、要地、要親事、要對方罷手，就算信錯了人也一樣。勇敢或易怒的人可能當眾揭穿勒索的人；收過封口費的人過幾年會回來再要。做了虧心事的人臨死前可能招認，家裡才知道這些年錯怪了誰（`src/hooks.cpp`、`data/events/hooks.json`）。
- 打聽是一場追查：先列出有動機的幾家，每問一個人就可能排除一家、聽到一個名字，或被人瞎猜帶偏；被問到自家的人一定替自家作證。
- 莊園法庭陪審：六個鄰居投票，看他們相信什麼、跟兩家的交情和恩怨，可能冤枉好人。莊頭三年一任，村民投票選，可以拉票；領主硬塞的莊頭會得罪全村。當了莊頭要收欠租、派勞役，也能在帳本上做手腳（`data/events/court.json`）。
- 壓力崩潰一年最多一次，同一件事崩潰兩次就垮掉；拿家裡人出氣，孩子長大會記得。
- 經濟（第五輪重新平衡）：每戶有屋後菜園（豆子、豬、雞、拾穗），15 畝地的六口之家平常年份勉強打平；交不出租時先賣糧（留 300 天口糧）；被牽走的牛要自己花 60 便士買回來。地租欠款和鄰居的借款分兩本帳記。鄰居告上莊園法庭討債時，家主可以交地、一次還清或賴帳。
- 家族只能由同姓血脈延續：家主死後若房子只能傳給外姓（入贅的丈夫、繼父），會先把在外幫傭或住在別家的子孫叫回來接手；找不到就算絕嗣（統計的存活率因此較誠實，約 85–90%）。
- 窮也有辦法：糧食見底時有「米缸見底」（向鄰居借糧、送孩子去幫傭、去領主林子下套子、教堂濟貧、勒緊褲帶）；計畫多了「打短工」和「偷獵」。「家裡知道什麼」會列出去年收成夠吃幾天、地租交了多少。
- 領主會老死，由繼承人接手莊園（以前領主死了就一直空著）。家主臨終前有「床前」：向繼承人吐露秘密、請神父做彌撒，或叮囑孩子「別結仇」／「記住誰欠了這個家」，影響繼承人接下多少舊恨。
- 開局不一樣：每局從幾種處境之一開始（上一代的官司、欠磨坊的錢、年輕時燒過別人的麥垛、說好的親事、領主看你不順眼、平常的一年；`data/events/openings.json`）。
- 領主也會報復：得罪領主太深（被勒索、頂撞、推託勞役），管家會上門加租；可以認、送禮賠罪或頂回去。莊頭連任兩屆以後，鄰居的票會越來越少。
- 世仇有配額：同一戶一年最多兩件世仇事件；報復計畫要先結怨（第 2 階）才能發起，醞釀更久、更容易被發現，放火成了一章裡的大事。說親失敗會說原因（世仇、名聲、窮、對方看上了別家）。
- 編年史按家主分章，每代家主有綽號，章末一行「這一代」回顧；結尾列出和別家的恩怨、欠債。
- 特質：個性（受父母與童年事件影響）、天生（可遺傳）、後天。
- 事件：`data/events/*.json`，共約 70 個，含條件、目標、選項、AI 權重、隨機結果。
- 家族階梯（`src/ambitions.cpp`）：農奴 → 自由佃農 → 自耕農（6 畝以上自由地）→ 小地主（40 畝、其中 20 畝自由地）；支線是家裡有人進教會、有兒子在城裡。自由地租輕（每畝 1 便士），領主的法庭也收不走。往上爬一階，貪心、有野心或本來就不和的人家會眼紅，其他人會另眼相看。
- 志向：每個家主（含 NPC）都有一個。玩家換家主時從三個裡選一個（依個性抽），志向分幾步（里程碑），相關計畫在 `p` 選單排在最前面並標 ★。沒做完的志向成了「上一代的心願」，下一代更容易抽到，完成時聲望加倍。完成後留下家族傳統。
- 人心（`src/minds.cpp`）：每年每個家主和跟你家有關的人定一個打算（志向、記仇、幫有難的朋友、說親、找活路，或者就過一天算一天），再按月慢慢付諸行動。記恨多半先悶著。你家的人做了大事，對方當場「記下了這筆帳／這份情」。朋友家有難會來幫；你家的人想幫別人，會先問家主。
- 全村一起過日子：每個成年人每年都有打算（志向、記仇、幫人、說媒、求偶、交朋友、或「過一天算一天」），不管離你家遠近，節奏都一樣，所以村裡別家的事也會自己推進、互相交織。按關係分圈（每季依關係圖重算）只決定誰會注意你家：聚光圈（最多 6 人：正在跟你家有事的）一季重新打一次主意；遠圈每年隨機有兩個人開始注意你家。`k` 家族報告會列「眼下跟你家有事的人」，`i` 可以細看一個人（志向、打算、對你家的好感和原因、欠債）；在暗地裡算計你的人只會顯示「看你家的眼神不太對」。
- 決定者（可換成模型）：`play --npc-model 指令` 讓村裡的人在規則允許的選項裡由模型挑（`--npc-scope all|near|spotlight`，預設 all = 全村；和你家不相干的遠方村民，給模型的感受裡不會硬塞你家家長）。`tools/npc_model.py` 用 Claude（寫得出「心想」的一句話）；`tools/npc_decider.py` 用決策模型 Perplexity pplx-decider（27B，經 OpenRouter 的 Decisions API，要 `OPENROUTER_API_KEY`；只挑不寫理由；也能用 `DECIDER_URL` 改接本機的 TinyJev；模型的機率會先攤平再和規則權重混合，見 `DECIDER_TEMP`／`DECIDER_MIX`）。全村每年的打算是一起問的，`play` 一次同時跑 16 個模型指令，所以每年不必一個一個等。`--npc-log 檔案` 記下每個回答，下次直接重放，不再叫模型，所以有模型的局也能一模一樣地重演。統計和測試不叫模型。
- 傳家之物：物品記錄製作者與歷任家主，嫁妝會帶走可攜帶的物品。
- 歷史時間軸：`data/history.json`（大饑荒、百年戰爭、黑死病、勞工法令、人頭稅、農民起義……）。

## 還沒做

細步進（逐分鐘）、重點日子、存檔、市鎮與商人出身、需求驅動的日常行為。

## 範例

`samples/` 裡有 100 年編年史。最新的是 `peasant-1340-seed12-round3.md`、`peasant-1340-seed6-round3.md`、`artisan-1340-seed4-round3.md`（第三輪修改後的版本）；再前一版是 `peasant-1340-seed20-arcs.md`、`peasant-1340-seed10-deathbed.md`。`peasant-1340-seed1-secrets.md` 是加入秘密與傳聞後的版本，`peasant-1340-seed5-manor.md` 是加入莊園制度後的版本，`peasant-1330-seed5-memory.md` 是加入記憶系統後的版本，其他三份更早。

`stats/` 裡是 200 局的統計：`00-baseline-peasant.md` 是加入長線故事前，`01-after-arcs-peasant.md` 是之後，`02-round2-fixes-*.md` 是第二輪評審修改後（史實模式存活約 85%），`03-round3-fixes-peasant.md` 是第三輪修改後（存活約 89%，放火每局 3.7 次），`04-round4-peasant.md`、`05-round5-peasant.md` 是互動模式與試玩修正後。`samples/play-1340-seed21-transcript.txt` 是一份互動模式的完整畫面（每次都選第一個選項的玩家，60 年）。Fable 的評審在 `../design/reviews/`。
